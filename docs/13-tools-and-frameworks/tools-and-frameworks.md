# AI Tools and Frameworks

## Why It Matters

Frameworks help turn model capabilities into real applications. They are useful
for orchestration, retrieval, agent workflows, observability, evaluation, and
deployment.

## Core Categories

- LLM application frameworks
- agent orchestration
- retrieval frameworks
- evaluation tools
- serving and routing tools
- observability platforms

## Important Frameworks

### LangChain
https://github.com/langchain-ai/langchain

Useful for building LLM applications, chains, retrieval flows, and integrations.

### LangGraph
https://github.com/langchain-ai/langgraph

Useful for stateful agent workflows and graph-based orchestration.

### LlamaIndex
https://github.com/run-llama/llama_index

Useful for RAG, document indexing, retrieval, and knowledge assistants.

### Semantic Kernel
https://github.com/microsoft/semantic-kernel

Useful for enterprise-friendly AI orchestration across languages and platforms.

### AutoGen
https://github.com/microsoft/autogen

Useful for multi-agent experiments and conversational agent workflows.

### LiteLLM
https://github.com/BerriAI/litellm

Useful for model routing, provider abstraction, and gateway patterns.

## Practice Milestones

- Build a single-prompt LLM utility with structured output.
- Add retrieval over local documents.
- Add tool calling for one external action.
- Add evaluation cases for expected and failure behavior.
- Add tracing or logging for the end-to-end workflow.
