# Career Paths & Portfolio Guide

## Career Roles by Skill Level

### Beginner (0-6 months)
| Role | Key Skills | Salary Range |
|---|---|---|
| **AI/ML Intern** | Python, basic ML, linear algebra | $50-80K |
| **Data Analyst** | SQL, Python, statistics, visualization | $60-90K |
| **Junior ML Engineer** | scikit-learn, pandas, model training | $80-110K |

### Intermediate (6-18 months)
| Role | Key Skills | Salary Range |
|---|---|---|
| **LLM Engineer** | Transformers, fine-tuning, RAG, prompt engineering | $110-150K |
| **MLOps Engineer** | Docker, K8s, CI/CD, model serving, monitoring | $120-160K |
| **NLP Engineer** | Tokenization, embeddings, sequence models, LLMs | $110-150K |
| **AI Product Engineer** | API design, LLM integration, UX for AI | $120-160K |

### Advanced (18-36 months)
| Role | Key Skills | Salary Range |
|---|---|---|
| **Senior ML/AI Engineer** | Distributed training, custom architectures, research | $150-200K+ |
| **AI Agent Architect** | Multi-agent systems, tool use, planning, memory | $160-210K+ |
| **AI Infrastructure Lead** | GPU clusters, inference optimization, LLMOps | $160-210K+ |
| **Applied AI Researcher** | SOTA models, papers, novel architectures | $170-250K+ |

## Portfolio Project Ideas

Build these 5 project types to demonstrate end-to-end capability:

### 1. LLM Application (Weeks 1-2)
Build a document Q&A chatbot using an open-source LLM + retrieval.
- **Stack**: Ollama, LangChain, Streamlit, ChromaDB
- **Showcases**: Prompt engineering, RAG basics, API integration
- **Deploy**: Docker + Railway/Hugging Face Spaces

### 2. Fine-Tuned Model (Weeks 3-4)
Fine-tune a small LLM on domain-specific data (e.g., customer support transcripts).
- **Stack**: Hugging Face Transformers, LoRA, Axolotl, Weights & Biases
- **Showcases**: Data prep, parameter-efficient fine-tuning, evaluation
- **Deploy**: vLLM + FastAPI endpoint

### 3. Advanced RAG Pipeline (Weeks 5-6)
Build a multi-stage RAG system with hybrid search and reranking.
- **Stack**: LlamaIndex, Qdrant/Weaviate, Cohere reranker, Langfuse tracing
- **Showcases**: Chunking strategies, hybrid retrieval, eval, observability
- **Deploy**: Kubernetes-ready with monitoring

### 4. AI Agent System (Weeks 7-8)
Create a multi-agent workflow (research agent, summarizer, writer).
- **Stack**: LangGraph/CrewAI, tool calling, memory, structured output
- **Showcases**: Agent patterns, tool design, state management, error handling
- **Deploy**: With human-in-the-loop approval gates

### 5. Multimodal / Diffusion (Weeks 9-10)
Build an image generation or vision analysis pipeline.
- **Stack**: Stable Diffusion, ComfyUI, CLIP, Gradio
- **Showcases**: Diffusion models, vision encoders, prompt crafting
- **Deploy**: Serverless (Replicate / Fal.ai)

## How to Present Your Portfolio

- **GitHub**: One repo per project with README, architecture diagram, demo GIF
- **Blog**: Write 500-word technical breakdowns for each project
- **Demo**: Deploy live apps so recruiters can interact
- **Resume**: Map each project to a bullet point under the relevant skill
